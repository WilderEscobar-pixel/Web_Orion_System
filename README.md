# Orion Systems — Empresa Autónoma en Latinoamérica

Sitio web oficial de Orion Systems. Especialistas en automatización de flujos de datos e inteligencia artificial.

## Tecnologías
- HTML5
- CSS3 (Custom Glassmorphism & Cosmic Animations)
- JavaScript Vanilla
- Integración con n8n Webhooks

## Cómo visualizar localmente
Simplemente abre `index.html` en cualquier navegador.
